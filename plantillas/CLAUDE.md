# Cómo usar mis skills

Usa las skills instaladas de forma proactiva cuando la tarea encaje, aunque no las nombre.
Si dos se solapan, sigue este reparto. Antes de empezar una tarea grande, dime en una
línea qué skills vas a usar.

## Diseño web y UI

1. **Dirección visual de algo nuevo** (landing, web, portfolio, página de producto):
   empieza con `taste-skill` (design-taste-frontend) para elegir dirección, tipografía,
   paleta e imágenes. Si necesitas datos concretos de paletas, fuentes o reglas de mi
   stack, consúltalos en `ui-ux-pro-max`.
2. **Construir y pulir**: usa `impeccable` (`/impeccable craft`, `polish`, `audit`,
   `critique`). Respeta la dirección elegida en el paso 1; no la sustituyas.
3. **Animación y microinteracciones**: `emil-skills` (`animate`, `review-animations`,
   `animation-performance`). En móvil web, `mobile-native`.
4. **Antes de dar algo por terminado**: pasa `emil-skills:break-ui` con datos extremos.
5. **Landing cinemática con scroll 3D**: solo si lo pido, `scroll-world` (cuesta dinero).
6. **Marca, logos, banners, slides**: `ui-ux-pro-max` (brand, design, banner-design, slides).

## Móvil

- React Native / Expo: `react-native-skills` para la estructura y el rendimiento, y
  `emil-skills:animate-expo` para las animaciones.
- Swift / iOS nativo: `emil-skills:write-swift` y `emil-skills:apple-design`.

## Diagramas y documentación técnica

- Arquitectura, secuencia, ERD, flujos, estados o timelines: `archify`. Si es sobre este
  repo, básate en el código real.

## Marketing y textos

- Textos de la web: `marketing-skills:copywriting`; para revisar textos existentes,
  `copy-editing`.
- Conversión de una página: `marketing-skills:cro`. Lanzamientos: `launch`. SEO:
  `seo-audit` y `ai-seo`. Estrategia general: `marketing-plan`.
- Si una tarea de diseño incluye textos, el copy lo decide `marketing-skills` y el
  aspecto visual las skills de diseño.

## Memoria y mejora continua

- `claude-mem` guarda el contexto entre sesiones: antes de preguntarme algo que ya
  pudimos haber hablado, busca con `mem-search`.
- `task-observer`: anota mis correcciones y patrones repetidos. No guardes en
  `skill-observations/` datos personales ni secretos.
